# References

When a video quotes someone, a book or an article, and the reference can be found, the app retrieves it, so you can go to the source.

## What it does

- Detects references in the transcript and description: people, books, papers, articles, talks, links.
- Looks each one up and attaches what it finds: a link, a title, an author, an abstract.
- Lists them per video and across a theme, to keep or explore further.
