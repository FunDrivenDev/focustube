# Notes

On each video you can write a side note, and it is kept. Kept [learnings](analysis.md#learnings) and [references](references.md) sit next to it.

## What it does

- Write and edit a note on a video, in Markdown; every edit is undoable.
- Link a note to a timestamp in the video.
- Search every note fuzzily, and browse them by theme.
- Export notes as Markdown files.
