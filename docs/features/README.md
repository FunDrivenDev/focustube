# Features

Each file describes one feature: what it is for, what it does, and what is still open. Nothing here is built yet; the app is the MOSST template renamed. What YouTube allows, and what it costs in requests and in account risk, is in [the research](../research/README.md). Every feature keeps the four design rules in `CLAUDE.md`: every action has a key, every setting lives in `⌘,`, every search is fuzzy, every action is undone rather than confirmed.

| Feature | In one line |
| --- | --- |
| [Themes](themes.md) | The entry point: a subject you want to learn about |
| [Sources](sources.md) | The channels and creators you trust about a theme |
| [Feed](feed.md) | Only the videos you chose, organized, without "next video" |
| [Feedback](feedback.md) | More, less, always, never, no shorts: on each video |
| [Preference learning](preference-learning.md) | The feed learns from your feedback and history |
| [Recommendations](recommendations.md) | New sources and videos, from searches or the app's suggestions |
| [Accounts](accounts.md) | Google and YouTube Premium, both optional |
| [YouTube data](youtube-data.md) | Titles, descriptions, transcripts, within the quotas |
| [Analysis](analysis.md) | Summaries and learnings from the transcripts |
| [References](references.md) | Books, articles and people a video quotes, retrieved |
| [Notes](notes.md) | A side note on each video, kept |
| [Storage](storage.md) | Everything local, in SQLite |
| [Agents](agents.md) | Claude Code or another agent, optional |
